# 民诉 分科规范

> 与 `CLAUDE.md` 配合使用。冲突时以本文件为准。

## 考试定位

- 程序法,客观题与主观题均考
- 得分点高度集中在**期限、管辖、程序顺序**上——这些是法条写死的,记准即得分,记错即失分
- 学理争议少,不需要处理学派问题

## 篇幅

**深入版上限:输入字数的 25%。**

比民法刑法略宽,原因是程序法的表格化内容多,表格本身占字数但信息密度高,不算冗余。上限不得超过 30%。

## 专属输出要求

| 情形 | 必须产出 |
|---|---|
| 出现任何期限 | 汇入本专题的**期限表**:事项 / 期限 / 起算点 / 可否延长 |
| 管辖问题 | **管辖表**:级别管辖 / 地域管辖 / 专属管辖 / 协议管辖,分列 |
| 程序阶段 | **流程图**(代码块),标明每一步的期限和主体 |
| 相似程序 | 对比表(如简易 / 小额 / 普通;一审 / 二审 / 再审) |
| 涉及"应当 / 可以" | ⚠️ 必须原样保留并加粗。这是命题重点,不得互换 |

## 冲刺版额外要求

除通用规格外,冲刺版必须包含:

1. **全科期限总表**——把所有专题的期限汇总到一张表,按事项排序
2. **管辖速查表**
3. **"应当 / 可以"对照清单**
