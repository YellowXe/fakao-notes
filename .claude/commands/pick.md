## 任务

用**两位老师的同一个专题**各产出一份深入版,写入:

```
<科目>/补充/专题NN <专题名>_<老师>.md
```

先输出两边的分组结果与字数,**停下等我确认**再开始。

⚠️ 两位老师的专题编号体系可能不同(同一个知识点未必是同一个专题号)。
若按专题号取到的内容明显不是同一主题,**停下报告**,由我指定各自的专题号。

## 然后给我这张对比表

| 维度 | 老师甲 | 老师乙 |
|---|---|---|
| 输入字数 / 输出字数 / 压缩比 | | |
| 明说「这是考点/勾一下/必考」次数 | | |
| 提到考情(「考过X年」「还没考过」)次数 | | |
| 口诀数量 | | |
| 对比表数量 | | |
| 给出法条编号的次数 | | |
| 有无主观题方法 | | |
| 相同压缩比下的信息密度(附判断依据) | | |

再补一段 200 字以内的主观评述:**谁的体系更清楚、谁更适合零基础起步**,并说明理由。
