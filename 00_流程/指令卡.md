# 指令卡

> 给**不支持 slash command 的工具**用(Reasonix、以及任何裸调 API 的场合)。
> Claude Code 直接用 `/check` `/deep` `/batch` `/backfill` `/pick` `/rollup`,不用抄这里。
>
> 每个代码块都是完整指令,复制即可。**每开新会话都要重新贴一次**——
> 分科规范文件不会自动加载,漏了它压缩比和专属要求会静默失效。

## 各工具的自动加载情况

| 工具 | `CLAUDE.md` | 目录映射 | 分科规范 | 反例样本 |
|---|---|---|---|---|
| Claude Code | ✅ 自动读项目根 | ❌ | ❌ | ❌ |
| Kiro | ✅ 已配 `.kiro/steering/` | ❌ | ❌ | ❌ |
| Reasonix | 走它自己的 project memory | ❌ | ❌ | ❌ |

后三列三个工具都不会自动读,所以下面每条指令都写了"读 xx"。
**CLAUDE.md 里已加了自我保护:读不到分科规范文件它会自己停下来问。**

## 3 · 验收(你自己看，六件事)

| 看什么 | 合格标准 |
|---|---|
| 覆盖完整 | 跨集专题的后半部分内容在不在 |
| **没有跨子学科混入** | 三国法专用:笔记内容应全属国际公法,不含私法/经济法的东西 |
| 压缩比 | frontmatter 输入/输出字数,三国法 ≤35% |
| 被舍弃的考点 | 有 → 上限过紧,上调 3 个点重跑 |
| **溯源表** | **抽 3–5 条,拿字幕原文片段回字幕里检索,搜不到就是编的** |
| 星级 / 页码 | ★★★ 对应老师说"必考/年年考"处;页码 `P9` 格式能对上精讲书 |

⚠️ 溯源表这一项是抽查幻觉最快的手段,别省。

对比基线:`99_归档_旧版笔记/01-主笔记/三国法/01-国际公法/002-专题二...md` 那份
当时只拿到 002 一个文件,是半个专题。新笔记里应出现**政府间国际组织**和
**国际法律责任**(在 003、004 里),没出现就是跨集合并没生效。


**专题多的科目(民法 40+)** —— 用脚本:

```bash
DRYRUN=1 ./run.sh 民法李建伟              # 先看分组对不对,不烧钱
CONC=1  ./run.sh 民法李建伟 01 02 03      # 首批三个
#   → 验收 → 回填错字表 →
CONC=3  ./run.sh 民法李建伟               # 放开剩余(Reasonix 保持 CONC=1)

SUB=国际私法 ./run.sh 三国法              # 三国法按子学科跑
```

脚本自带:目录映射、三国法二级分组、集号升序合并、字数校验、幂等跳过、
主线老师判断(非主线自动进 `补充/`)、并发控制。

## 四个坑

1. **别让它一次跑完整科才给你看。** 前 3–5 个专题必须逐个验,批量是模板定型之后的事
2. **三国法必须带子学科。** 只说"专题02"它可能取到三个子学科的三份文件合并成一个,
   而结果看起来是完整的
3. **跑批期间别改 `CLAUDE.md` 和分科规范。** 前缀一变 prefix cache 全失效,
   成本明显上升。要改等这批跑完
4. **每开新会话都要重新说"读 00_流程/目录映射.md 和 00_规范/xx.md"。**
   现在 CLAUDE.md 加了自我保护会替你兜底,但别指望它

## 换模型时额外注意

| 事项 | 做法 |
|---|---|
| 温度 | **0–0.3**。这一条的收益可能超过所有规范条文 |
| 深入版 | 用**最强**的模型。两万字非结构化输入,是编造的高发区 |
| 预习/冲刺版 | 可用便宜模型。输入已是自己产出的结构化 md,本质是压缩重排 |
| 抽查校验 | 可用便宜模型。拿溯源表片段回字幕里检索比对,纯机械活 |
| 反例样本 | 幻觉率高的模型**务必**带上 `00_样本/反例/` |
