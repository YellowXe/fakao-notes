# 行政法与行政诉讼法 分科规范

> 与 `CLAUDE.md` 配合使用。冲突时以本文件为准。

## 考试定位

- 实体法(行政法)与程序法(行政诉讼法)合为一科,客观题与主观题均考
- **本科最大特征:实体与程序高度耦合**。一个知识点常横跨两侧——如"行政行为的合法性要件"决定"法院的判决方式","行政主体的认定"决定"谁是被告"
- 复议与诉讼的衔接是高频命题区

## 篇幅

**深入版上限:输入字数的 25%。** 上限不得超过 30%。

## 专属输出要求

| 情形 | 必须产出 |
|---|---|
| 受案范围 | **可诉 / 不可诉对照表**,不可诉的列全法定排除事项 |
| 被告确定 | **情形—被告对照表**(经复议、授权、委托、联合作出等,逐种列出) |
| 判决方式 | **情形—判决方式对照表**:撤销 / 变更 / 确认违法 / 确认无效 / 履行 / 驳回 |
| 复议与诉讼 | **两条路径对比表**:受案范围 / 期限 / 管辖 / 审查强度 / 是否为前置 |
| 期限 | 汇入期限表,起算点单独成列 |
| 行政行为分类 | 分类表,并标明各类的合法性要件差异 |

## 双链要求(本科加强)

本科是八科中**双链需求最高**的,因为实体与程序互相指向。

- 实体侧的知识点若直接决定程序侧结论,**必须双链**(如行政主体 → 被告确定)
- 反向同理
- 例外:本科单个专题笔记的链接数上限放宽到 **0–6 个**(通用规则是 0–3)

## 学理与争议处理

- 老师明确区分"通说 / 争议"的保留标注
- 不得自行补充学理争议
- 涉及新旧行政诉讼法、新司法解释变化的,老师若说明,必须保留并标 `#易错`
