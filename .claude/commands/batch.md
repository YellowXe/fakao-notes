# 批量深入版:$1 专题 $2

## 先读这些文件(读完先声明你读到了哪几个)

1. `CLAUDE.md` —— 特别是开头的「五条铁律」
2. 分科规范文件 —— 按下表确定:
   - `国际法` / `国际私法` / `国际经济法` → `00_规范/三国法.md`
   - 含下划线的取前段:`民法_张` → `00_规范/民法.md`
   - 其余同名:`刑法` → `00_规范/刑法.md`
3. `00_样本/反例/反例_典型幻觉形态.md`

⚠️ 分科规范文件读不到就**中止并报告**。

## 任务

依次处理 `00_素材/$1/` 中专题号在 **$2** 范围内的专题,每个产出一份深入版。

### 开跑前

一次性输出全部分组结果(专题号 → 文件列表 → 字数),**停下等我确认**。
其中字数 < 2000 的文件所属专题**整个跳过**,并在最后汇总报告。

### 逐个处理

- 一次一个专题,**每个完成后输出自检表**,再进入下一个
- 目标文件已存在则**跳过**(幂等),并说明跳过原因
- 任一专题自检出现「因篇幅上限舍弃考点」→ **停下报告**,不要继续后面的

### 全部完成后

1. 汇总表:专题号 / 输入字数 / 输出字数 / 压缩比 / 是否触及上限 / 是否跳过
2. **停下。不要生成 `_预习.md` 和 `_冲刺.md`**(那是 `/rollup` 的事)
3. 提醒我该跑 `/backfill $1` 了

⚠️ 首次批量建议只跑 3–5 个专题就停,回填错字表后再放开剩余的。
