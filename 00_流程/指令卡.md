# 指令卡

> 给**不支持 slash command 的工具**用(Reasonix、以及任何裸调 API 的场合)。
> Claude Code 直接用 `/check` `/deep` `/batch` `/backfill` `/pick` `/rollup`,不用抄这里。
>
> 每个代码块都是完整指令,复制即可。**每开新会话都要重新贴一次**——
> 分科规范文件不会自动加载,漏了它压缩比和专属要求会静默失效。

## 各工具的自动加载情况

| 工具 | `CLAUDE.md` | 分科规范 | 反例样本 |
|---|---|---|---|
| Claude Code | ✅ 自动读项目根 | ❌ | ❌ |
| Kiro | ✅ 已配 `.kiro/steering/` | ❌ | ❌ |
| Reasonix | 走它自己的 project memory | ❌ | ❌ |

后两列三个工具都不会自动读,所以下面每条指令都写了"读 xx"。
**CLAUDE.md 里已加了自我保护:读不到分科规范文件它会自己停下来问。**

## 3 · 验收(你自己看，六件事)

| 看什么 | 合格标准 |
|---|---|
| 覆盖完整 | 跨集专题的后半部分内容在不在 |
| 压缩比 | frontmatter 输入/输出字数,三国法 ≤35% |
| 被舍弃的考点 | 有 → 上限过紧,上调 3 个点重跑 |
| **溯源表**(新增) | **抽 3–5 条,拿字幕原文片段去字幕里检索,搜不到就是编的** |
| 星级 | ★★★ 对应老师说"必考/年年考"处,不是它自己觉得重要 |
| 页码 | `P9` 格式,能对上精讲书 |

⚠️ 溯源表这一项是抽查幻觉最快的手段,别省。

## 7 · 批量

**专题少的科目(三国法约十个)** —— 交互式:

```
读 CLAUDE.md、00_规范/三国法.md、00_样本/反例/反例_典型幻觉形态.md。

依次处理国际法专题 03 起的剩余专题,一次一个,每个完成后输出自检表再进入下一个。
目标文件已存在则跳过。任一专题自检出现"因篇幅上限舍弃考点"就停下报告。
全部完成后停下,不要生成预习版和冲刺版。
```

**专题多的科目(民法 40+)** —— 用脚本:

```bash
DRYRUN=1 ./run.sh 民法_张          # 先看分组对不对,不烧钱
CONC=1  ./run.sh 民法_张 01 02 03  # 首批三个
#   → 验收 → /backfill 民法_张 →
CONC=3  ./run.sh 民法_张           # 放开剩余(Reasonix 保持 CONC=1)
```

脚本自带:按专题分组、集号升序、字数 <2000 跳过、输出已存在跳过、并发控制。

## 三个坑

1. **别让它一次跑完整科才给你看。** 前 3–5 个专题必须逐个验,批量是模板定型之后的事
2. **跑批期间别改 `CLAUDE.md` 和分科规范。** 前缀一变 prefix cache 全失效,成本明显上升。要改等这批跑完
3. **每开新会话都要重新说"读 00_规范/xx.md"。** 现在 CLAUDE.md 加了自我保护会替你兜底,但别指望它——用 slash command 或直接复制上面的指令块最省心

## 换模型时额外注意

| 事项 | 做法 |
|---|---|
| 温度 | **0–0.3**。这一条的收益可能超过所有规范条文 |
| 深入版 | 用**最强**的模型。两万字非结构化输入,是编造的高发区 |
| 预习/冲刺版 | 可用便宜模型。输入已是自己产出的结构化 md,本质是压缩重排 |
| 抽查校验 | 可用便宜模型。拿溯源表片段回字幕里检索比对,纯机械活 |
| 反例样本 | 幻觉率高的模型**务必**带上 `00_样本/反例/` |
