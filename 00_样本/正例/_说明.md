# 正例范本

本目录存放**已验收通过**的深入版笔记,供便宜模型对齐格式。

命名:`<部门法>_<子学科>_专题NN.md`,例如 `三国法_国际公法_专题02.md`。

## 进入本目录的条件(缺一不可)

| 条件 | 怎么确认 |
|---|---|
| `verify.sh` 全部片段命中 | `./verify.sh <素材目录> <专题号>` 退出码 0 |
| 跨集覆盖完整 | 各集内容都在,没有只处理前半部分 |
| 「被舍弃的考点」为空 | 看自检报告 |
| 星级抽查通过 | ★★★ 确实对应老师说"必考/年年考"处 |
| 人工读过一遍 | ⚠️ 范本的错误会被复制到几十个专题 |

**没验收过的产出不要放进来。** 宁可暂时没有范本。

## 怎么用

在给便宜模型的 prompt 里附上本科范本,并同时附上 `CLAUDE.md` 的
「参考样本的使用」一节。`run.sh` 已自动引用本目录。

⚠️ 范本只用于对齐**格式**:表格用法、星级位置、frontmatter 字段、引用块、
校对说明的写法、语言颗粒度。

❌ 不得取用范本里的任何法律内容
❌ 不得照搬范本的小节构成(范本有 `## 主观题` 不意味着别的专题也要有)
❌ 范本篇幅不是目标篇幅(篇幅只由「输入字数 × 分科上限」决定)

## 跨科使用

优先用**同科**范本。没有同科范本时可用近似科目的,但要在 prompt 里写明
"仅对齐格式,本科的专属输出要求见分科规范"。

三国法三个子学科差异较大(公法考得浅、私法有系属公式、经济法有贸易术语对比),
**三个子学科各自需要范本**。
