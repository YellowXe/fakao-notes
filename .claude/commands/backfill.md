# 回填分科规范:$ARGUMENTS

## 先读这些文件

1. `00_流程/目录映射.md` —— 查出分科规范文件与笔记所在目录
2. 上一步查到的 `00_规范/<部门法>.md`
3. `CLAUDE.md`「回填分科规范文件」节
4. 该部门法目录下**已生成的全部深入版**的「字幕校对说明」小节
   （三国法要覆盖 `国际公法` / `国际私法` / `国际经济法` 三个子目录）

## 任务

将实际改动合并写入分科规范文件:

1. **专属 ASR 错字表** —— 去重,按出现频次降序;出现 **≥3 次**标 `高频`
2. 属于「两边都是真词」性质的 → 放进**高危同音组**,**不要**放进可直接替换表
3. **已知待核条目** —— 汇总各深入版中标 `【?】` 的条目
4. **校准记录** —— 填入实测输入/输出字数、压缩比、触及上限的专题清单

## 输出

1. 本次新增/合并了哪些条目(表格)
2. 有没有条目被判定为高危同音组而未进替换表(列出并说明理由)
3. 压缩比实测汇总,以及**是否建议调整篇幅上限**(按 CLAUDE.md「篇幅上限的调整判据」
   给结论,但**不要自己改上限**)

⚠️ 只改分科规范文件,不要改 `CLAUDE.md`,不要动已生成的笔记。
⚠️ 三国法三个子学科共用一份规范文件,错字表合并时不要按子学科拆开。
