## 考试定位

以下均出自字幕中老师本人的表述:

- **只在客观题出现,主观题无三国法**
- 国公 + 国私 + 国经合计约 **20 分**
- 门槛高(术语陌生),但**分值转化率高**——考查范围严格受大纲限制,且考得浅,属入门级考查
- 国际公法每年约 **4—6 分**,大纲 8 章
- 国际公法试题三字特点:**散、细、新**

## 篇幅

**深入版上限,按专题跨集数分档:**

| 专题规模 | 上限 |
|---|---|
| 单集 / 两集 | **35%** |
| 跨三集及以上的大专题 | **38%** |

分档的理由:跨集大专题的考点密度明显更高,而 35% 这个数的实测样本只有
"一个单集专题 + 半个跨集专题"。全科统一上调会让单集专题也跟着松掉。

实测:专题一 + 专题二上半,输入约 2.4 万字,输出 1.64 万字 = **36%**,信息未丢失且未见冗余。故 35% 是合适上限,是八科中最宽的——因为本科"考得浅",单位字数承载的考点密度低,压缩空间不如民刑。

⚠️ **该实测样本是"一个单集专题 + 半个跨集专题"。** 完整跨集大专题(如专题二全三集)
考点密度更高,首次跑到时超标属正常现象。处理次序:

1. 先删自创结构(章节回顾表、内容小结之类,规范从未要求)
2. 再压案例叙述与非考点背景
3. **仍超标且未舍弃考点 → 上调至 38%**,不要硬压
4. **「字幕校对说明」不计入字数,任何情况下不得删减** —— 它是本科错字表的数据源,
   而三国法 ASR 错字尤其多

## 三个子学科

⚠️ **素材没有按子学科分目录。** `00_素材/三国法/` 一个目录里混装三个子学科,
靠**文件名**区分:

```
001_国际法 - 专题01：导论_clean.txt          ← 国际公法
031_国际私法 - 专题01：导论_clean.txt         ← 国际私法
055_国际经济法 - 专题01：导论_clean.txt       ← 国际经济法
```

**三个子学科各自都有「专题01」。必须按「子学科 + 专题号」二级分组**,
否则三份不相干的内容会被合并成一个文件,而结果看起来仍然完整。

匹配顺序:先 `国际私法` → 再 `国际经济法` → 最后 `国际公法`/`国际法`。
颠倒会把私法和经济法全部误判进公法。详见 `00_流程/目录映射.md`。

输出分三个目录:`三国法/国际公法/`、`三国法/国际私法/`、`三国法/国际经济法/`。
**三个子学科各出一套 `_预习.md` / `_冲刺.md`**,不要合成一份——它们是三门独立学科。

老师在讲每个子学科前会单独交代该科怎么讲、怎么学——这部分归入该子学科的
`000-学科导学.md`,**不要重复写进每个专题笔记**(否则你会读到几十遍)。
文件名里没有「专题N」的素材通常就是这类导学。

## ⚠️ 本科触发词变体(自检计数必读)

**杨老师不使用「必考」「年年考」「这是考点」「考试会考」这类字样。** 他的考点提示
一律是「勾X」——勾一下 / 勾一勾 / 勾一些 / 勾出来 / 勾出。

而「勾」是 ASR 高频失真字,常被识别成:

| 错 | 对 |
|---|---|
| 构出 / 扣出 / 够出 | 勾出 |

⚠️ **本科自检的触发词计数表必须改用下面这组变体,否则计数恒为 0**,进而误判
「老师没有任何考点表态」,把该标星的考点全部漏标:

| 原模板触发词 | 本科实际检索词 |
|---|---|
| 这是考点 / 考试会考 / 勾一下 | 勾一下、勾一勾、勾一些、勾出来、勾出、**构出**、**扣出**、**够出** |
| 必考 / 年年考 | ——(本科不出现,★★★ 一律改由**考情**判定:"连续两年考察""高频考点""考过三回") |
| 易错 / 容易错 / 陷阱 | 易错、容易错、陷阱、**易混辨析**(ASR 亦作"一混辨析") |
| 还没考过 / 没考过 | 还没考过、没考过、**没有考过** |

⚠️ 计数时注意「勾出来」包含「勾出」,**会重复计数**,须去重(勾出实际数 = 勾出总数 − 勾出来数)。

⚠️ 「够出」在专题02 中出现 0 次,仍列入检索表作预防——同音变体一旦漏检就是静默失败。
