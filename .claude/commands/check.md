# 素材体检:$1

## 先读这些文件(读完先声明你读到了哪几个)

1. `CLAUDE.md`
2. 分科规范文件 —— 按下表确定:
   - `国际法` / `国际私法` / `国际经济法` → `00_规范/三国法.md`
   - 含下划线的取前段:`民法_张` → `00_规范/民法.md`
   - 其余同名:`刑法` → `00_规范/刑法.md`

⚠️ 分科规范文件读不到就**中止并报告**,不要用通用规则继续。

## 任务

**只做体检,不要生成任何笔记文件。**

针对 `00_素材/$1/`:

1. 列出全部文件的**文件名**与**字数**(表格,按文件名排序)
2. 按 CLAUDE.md「输入」节的规则做**专题分组**,输出「专题号 → 文件列表」
   - 只抽两个数字:开头连续数字 = 集号;`专题` 之后的连续数字 = 专题号
   - 不要解析整个文件名
3. 单列一节标出**字数 < 2000** 的文件
4. 单列一节标出**同专题内字数明显偏小**的文件(低于同组中位数 50% 即算)

## 输出末尾给结论

一句话:**可以开跑** / **必须先重跑清洗**(并列出是哪几个文件)。

⚠️ 拿残缺素材生成的笔记**结构看起来是完整的**,事后极难发现。宁可停在这一步。
