# 自检报告模板

自检报告**必须写成文件**,路径:

```
<部门法>/_自检/专题NN.md
三国法/<子学科>/_自检/专题NN.md
```

⚠️ 只输出在对话里不算 —— 会话一关就没了,而且无法用脚本校验。
自检报告**不计入笔记篇幅上限**。

---

## 为什么溯源片段必须原样照抄字幕

`verify.sh` 会把片段拿回字幕里做**逐字检索**。所以:

- ✅ **原样照抄字幕**,包括 ASR 错字。字幕写"管辖惠民"就照抄"管辖惠民"
- ❌ 不要抄成笔记里改正后的表述("管辖豁免"),否则检索必然失败,报出一堆假警报
- ❌ 不要省略、缩写、加省略号
- 长度 **8–20 字**,取一段连续的、能唯一定位的文字
- **必须用反引号包裹**,脚本靠反引号提取
- ⚠️ **「## 溯源」小节内除片段外不要出现任何反引号。** 标签(`#高频`)、文件名
  (`xxx_clean.txt`)、字段名一律不加反引号,否则会被当成待检片段而报假失败
- 片段**不要跨行截取**。清洗稿有单行版也有多行版,换行是清洗产物

片段的作用是"这句话在字幕第几处"的坐标,不是"笔记写得对不对"的证明。

## 溯源

⚠️ 片段用反引号包裹,原样照抄字幕(含 ASR 错字),8–20 字。

| 类型 | 笔记中的表述 | 字幕原文片段 |
|---|---|---|
| 法条 | 《民法典》【原文未引法条】 | `民法典里面是有明确规定的` |
| 数字 | 普通期间 3 年 | `普通的诉讼时效期间是三年` |
| 数字 | 最长保护期间 20 年 | `不是十年,是二十年,别记错` |
| 真题 | (无) | —— |
| 口诀 | 登记生效为原则 | `记住这个口诀,登记生效为原则` |

某类超过 20 条时,列出前 20 条并注明总数。

### ⚠️ 溯源表前必须先报「总数 / 覆盖数」

否则无法判断这张表填全了没有:

| 类型 | 笔记中共有 | 本表覆盖 |
|---|---|---|
| 法条编号 | | |
| 数字(期限/比例/金额/年龄/个数/海里/年份) | | |
| 真题 | | |
| 口诀 / 必背金句 / 答题模板 | | |

**`verify.sh` 只能验「填进来的对不对」,验不了「该填的填没填」。**
溯源表填得越少,越容易全部命中 —— **少填不是通过,是绕过。**

> 实测参照:输入 30,392 字的专题产出 **33 条**溯源片段;
> 另一份输入 39,344 字、数字密度更高的专题(海洋法,全篇海里数与年份)
> 只填了 **16 条** —— 虽然 16 条全部命中,但大量数字实际未经任何校验。
>
> `verify.sh` 现在会同时报出「笔记中出现数字 N 处,溯源表 M 条」,
> 比例明显失衡时给出警告。
⚠️ 找不到出处的条目,**回到笔记里删掉它**,不要留在表里做解释。

## 校验

写完后跑:

```bash
./verify.sh 民法李建伟 07
```

脚本会把「## 溯源」小节里的每个片段拿回素材字幕逐字检索。搜不到的会列出来——
**那基本就是编造的**,或者是片段没照抄原文。两种情况都要处理。
