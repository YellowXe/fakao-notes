# 民法 分科规范

> 与 `CLAUDE.md` 配合使用。冲突时以本文件为准。

## 考试定位

- 体量最大的部门法,客观题与主观题**均考**,主观题必出
- 学理空间大,存在通说与少数说的取舍
- 制度之间高度交织(如无权代理 / 表见代理 / 无权处分 / 善意取得常在同一道题里绞在一起)

## 篇幅

**深入版上限:输入字数的 22%。**

定这个数的依据:按输入约 48 万字估算,22% ≈ 10.5 万字,以密集法律笔记约 9000 字/小时计约 12 小时读完,给真题和回看留出余量。若跑完首个专题后发现干货被压掉了,再上调,但**不得超过 28%**。

## 专属输出要求

深入版中,遇到下列情形必须产出对应结构:

| 情形 | 必须产出 |
|---|---|
| 两个及以上相似制度 | **要件对比表**,列全:构成要件 / 法律后果 / 举证责任 / 典型区分点 |
| 涉及期间、时效、除斥期间 | **时间轴或期限表**,起算点单独成列(起算点是主要命题点) |
| 一个纠纷涉及多方 | **法律关系图**(代码块画),标明每条线是何种请求权 |
| 有原则—例外结构 | 原则 → 例外 → 例外的例外,三层表格 |

## 学理与争议处理

- 老师明确区分"通说 / 少数说 / 争议"的,**保留标注**,并注明老师本人主张哪一说
- 老师未提及争议、直接给结论的,**照写,不得自行补充学理争议**
- 涉及新司法解释与旧规则冲突时,老师若说明了新旧变化,必须保留,并标 `#易错`
