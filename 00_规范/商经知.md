# 商经知 分科规范

> 与 `CLAUDE.md` 配合使用。冲突时以本文件为准。
>
> ⚠️ 若不整理本科,直接删除此文件即可。

## 考试定位

- 由多个相互独立的板块拼成:商法(公司、合伙、破产、票据、保险、海商等)+ 经济法 + 知识产权
- **板块之间几乎不互相引用**,这一点与其他各科不同——不要强行建立跨板块双链
- 记忆型与规则型混合,数字密集(表决比例、期限、出资、赔偿标准)

## 篇幅

**深入版上限:输入字数的 22%。** 上限不得超过 28%。

## 专属输出要求

| 情形 | 必须产出 |
|---|---|
| 出现表决比例、持股比例、出资比例 | **比例表**——本科最高频命题点,必须单独成表,不得混在正文 |
| 组织形式对比 | 对比表(有限责任公司 / 股份有限公司 / 普通合伙 / 有限合伙 等) |
| 期限 | 期限表,起算点单独成列 |
| 程序性内容(破产、清算) | **流程图**(代码块) |
| 知识产权 | **三权对比表**:专利 / 商标 / 著作权,横向对比保护期 / 取得方式 / 权利内容 / 侵权例外 |

## 板块隔离规则

- frontmatter 中 `专题` 字段后加板块标识,便于筛选,例:`专题: "05"` + `板块: 公司法`
- 冲刺版按**板块**分节,不做跨板块的统一辨析表
- 双链仅在同一板块内部使用

## 冲刺版额外要求

1. **全科比例总表**(表决、持股、出资)——本科冲刺第一优先级
2. **期限总表**
3. **知识产权三权对比总表**
