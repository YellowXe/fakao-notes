# 法考笔记

## 目录约定

```
00-字幕/         原始字幕 txt(按科目/部门法分文件夹)
01-主笔记/       按集,一集一份,信息完整。唯一读原文的产物
02-预习/         按章合并,15 分钟建框架
03-冲刺/         按部门法一份,考前最后一遍
```

三版是**派生关系**,不是三次独立处理:

```
字幕 → 主笔记 ─┬→ 压缩 → 预习版
               └→ 抽取 → 冲刺版
```

好处:原文只读一遍(省 2/3 成本),且三版天然对齐,冲刺版每条都能溯源到主笔记。
