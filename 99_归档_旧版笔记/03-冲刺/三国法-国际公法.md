## 一、易混辨析

### 1. 渊源 / 非渊源

| 是渊源(仅三项) | 不是渊源 |
|---|---|
| 国际条约、国际习惯、一般法律原则 | 学说、判例、国际组织决议、一国法的涉外部分 |

**同一命题的两种问法**:①是不是国际法的表现形式 ②国际法院能不能直接引用来判案。答案一致。

### 2. 一般法律原则 / 基本原则

| | 一般法律原则 | 基本原则 |
|---|---|---|
| 范围 | 大(包含基本原则) | 小 |
| 适用领域 | 可能只适用某一领域 | **必须适用国际法所有领域** |
| 例 | 区分对象原则、人道主义原则(仅武装冲突法) | 主权平等、不干涉内政、不使用武力、和平解决争端、民族自决、善意履行义务 |
| 是否渊源 | 是 | 是(且具**强行法**性质) |

### 3. 民族自决原则 / 其中的独立权

| | 适用范围 |
|---|---|
| 民族自决原则**本身** | 所有民族(含中国 56 个民族;国内法体现为民族自治权) |
| 其中的**独立权** | **仅**殖民统治下民族的独立 |

### 4. 管理统治行为 / 商劳赔财知

| | 管理统治行为 | 商劳赔财知 |
|---|---|---|
| 内容 | 立法、司法、行政 | 商业活动、境内劳动合同、境内行为致损害赔偿、财产权益、知识产权 |
| 管辖豁免 | **享有** | **不享有** |
| 我国法院管辖权 | 原则上无 | 有 |
| 转化条件 | 放弃(自愿+特定+明确) | —— |

### 5. 管辖豁免 / 执行豁免 ★高频陷阱

| | 管辖豁免 | 执行豁免 |
|---|---|---|
| 商劳赔财知 | 不享有 | **仍享有** |
| 突破方式 | 放弃 | ① 明示或默示放弃 ② 为执行已生效裁判 |
| 突破后范围 | 我国法院有管辖权 | ②的情形下**仅限用于商业活动且与诉讼有联系的财产**,非"任何财产" |

### 6. 明示放弃 / 默示放弃 / 不构成放弃

| 明示 | 默示(关键字"**诉**") | 不构成 |
|---|---|---|
| 元首公开表示 | 主动起诉 | 出庭仅为抗议管辖权、主张豁免 |
| 外交部发言人就该案表示 | 出庭应诉 | 同意适用中国法律 |
| | 提起或被提起反诉 | |
| | 作为第三人参加诉讼 | |
| | 提交案件事实证据、法律答辩意见 | |

### 7. 承认新国家 / 承认新政府 ★

| | 承认新国家 | 承认新政府 |
|---|---|---|
| 判断标准 | 被承认对象**有**领土变更(合并/分离/分立/独立) | **无**领土变更,既有领土内政权更迭 |
| 是否看措辞 | **一律不看** | **一律不看** |
| 法律后果 | **无法撤回** | **同时撤销**对该领土内旧政府的承认 |
| 例 | 前苏联分立出 15 国;乌境内四地宣布独立后被承认 | 1949 年对中华人民共和国的承认;塔利班改国号"阿富汗国"后被承认 |

### 8. 默示承认的四种行为 / 不构成承认

| 构成 | 不构成 |
|---|---|
| 建立外交关系(互设使馆) | 缔结非政治性条约(如避免双重征税协定) |
| 建立领事关系(互设领馆/接受其领事) | 投票支持加入非"仅对国家开放"的组织(**WTO**) |
| 缔结**政治性**条约(友好同盟、互助攻防) | 事实上的承认(如与叛乱组织签石油购买协议) |
| 投票支持加入**仅对国家开放**的组织(**联合国**) | |

### 9. 事实上的承认 / 法律上的承认

| | 事实上的承认 | 法律上的承认 |
|---|---|---|
| 可否反悔 | 可随时反悔 | 不可(新国家) |
| 法律后果 | 无。对方不能诉至国际性法院 | 认可对方同为国际法主体,可被诉 |
| 法考 | **不考** | 考 |

### 10. 分离 / 分立 / 独立 ★★

| | 原母国 | 有无殖民统治背景 | 债务继承效果 |
|---|---|---|---|
| **分离** | 还在 | 无 | **按比例**继承 |
| **分立** | 消失 | 无 | **按比例**继承 |
| **独立** | 还在(宗主国) | **有,仅限摆脱殖民统治** | **不予**继承 |

**题干识别**:"宣布独立" = 分离;"摆脱该国殖民统治而独立" = 独立。

### 11. 四种国家变化下的债务继承

| 变化 | 效果 |
|---|---|
| 合并 | 全部继承 |
| 分离 | 按比例继承 |
| 分立 | 按比例继承 |
| 摆脱殖民统治而独立 | 不予继承 |

### 12. 三类继承对象的规则

| 对象 | 规则 | 考频 |
|---|---|---|
| 条约 | 只继承**与领土划界有关**的 | 有 |
| 财产 / 档案 | 领土实际生存原则(= 与土地最密切联系) | 几乎不考 |
| 债务 | 国家非恶债三要件 + 看国家变化 | **最高** |

## 三、原则 → 例外 →(例外的例外)

| 原则 | 例外 | 再例外 |
|---|---|---|
| 国际习惯一旦形成约束所有国际法主体 | **持续反对者**不受约束 | 须同时满足自始 + 持续一贯反对;形成时未反对、或事后某届政府承认过,均丧失该地位 |
| 不使用武力或武力威胁 | 国家自卫行动;安理会授权的武力行动 | 此二例外虽用武力,仍属**和平手段** |
| 民族自决原则适用于所有民族 | 其中独立权仅限殖民统治下民族 | 非殖民统治下:主权原则 > 民族自决;殖民统治下:民族自决 > 主权原则 |
| 外国国家管理统治行为享有管辖豁免 | 自愿 + 特定 + 明确地放弃 | 同意适用中国法**不**视为放弃;出庭抗辩管辖权**不**视为放弃 |
| 商劳赔财知不享有管辖豁免 | 但仍享有**执行豁免** | 放弃执行豁免,或为执行已生效裁判(且仅限商业活动相关财产) |
| 在中国境内履行的劳动合同纠纷无管辖豁免 | 涉及**特权与豁免**另有协议的除外 | 使馆聘司机/保洁/厨师 → 我国管;聘文化参赞/武官/外交秘书 → 特别法优先 |
| 继承适用国际法一般规则 | **另行协议优先** | —— |
| 条约继承 | 只有与领土划界有关的才须继承 | —— |
| 国家债务可继承 | 仅**国家非恶债**;恶债不继承 | 三要件缺一即无继承可能 |

## 四、口诀与老师原话

- **商 劳 赔 财 知** —— 外国国家不享有管辖豁免的五类行为。(国际公法第一个口诀)
- 国际公法试题三字特点:**散、细、新**。
- **和平不等于非武力。**
- 内政**不是地理概念,是管辖权概念**。
- 渊源"其他啥啥都不是"——**说不出来更好,说出来反而容易混**。
- 判断承认新国家还是新政府,**不看承认者说了啥,看被承认对象有没有领土变更**。
- 分离与独立,**继承效果正好相反**。
- 精讲阶段**重在理解**;是否理解**不要妄自判断,要做题**。
- 有效纠错 = 回到精讲书查**错的原因**。
