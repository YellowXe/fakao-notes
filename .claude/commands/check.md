# 素材体检:$ARGUMENTS

## 先读这些文件(读完先声明你读到了哪几个)

1. `00_流程/目录映射.md` —— 查出本次要用的**分科规范文件**、输出目录、老师名
2. 上一步查到的 `00_规范/<部门法>.md`
3. `CLAUDE.md`「输入」节

⚠️ 分科规范文件读不到就**中止并报告**,不要用通用规则继续。
⚠️ 目录名和规范文件名有两处不一致(`民诉法`→`民诉.md`、`行政法`→`行政法与行政诉讼法.md`),
**查表,不要靠字符串推断**。

## 任务

**只做体检,不要生成任何笔记文件。**

针对 `00_素材/$ARGUMENTS/`:

1. 列出全部文件的**文件名**与**字数**(表格,按文件名排序),并给出总字数
2. 做**专题分组**,输出「专题号 → 文件列表(按集号升序)→ 组内总字数」
   - 只抽两个数字:开头连续数字 = 集号;`专题` 之后的连续数字 = 专题号
   - 不要解析整个文件名(分隔符风格不统一)
3. **若本次是三国法,必须按「子学科 + 专题号」二级分组**,并单独列出三个子学科各自的
   专题清单。⚠️ 三个子学科各自都有「专题01」,只按专题号分组会把不相干的内容合并
4. 单列一节标出**字数 < 2000** 的文件
5. 单列一节标出**同专题内字数明显偏小**的文件(低于同组中位数 50% 即算)
6. 单列一节标出**文件名里找不到「专题N」**的文件(通常是学科导学,需另行处理)

## 输出末尾给结论

一句话:**可以开跑** / **必须先重跑清洗**(并列出是哪几个文件)。

⚠️ 拿残缺素材生成的笔记**结构看起来是完整的**,事后极难发现。宁可停在这一步。
