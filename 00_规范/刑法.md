# 刑法 分科规范

> 与 `CLAUDE.md` 配合使用。冲突时以本文件为准。

## 考试定位

- 客观题与主观题**均考**,考得深
- 存在明确的**学派差异**:犯罪构成的两阶层体系 vs 四要件体系。不同老师采用不同体系,表述与推理路径都不同
- 分则部分靠"此罪与彼罪"的辨析得分

## 篇幅

**深入版上限:输入字数的 22%。** 上限不得超过 28%。

## 专属输出要求

| 情形 | 必须产出 |
|---|---|
| 犯罪构成分析 | **按主线老师采用的体系**列表(两阶层或四要件),不得混用两套体系 |
| 相似罪名 | **此罪彼罪对比表**:客体 / 客观行为 / 主观方面 / 主体 / 关键区分点 |
| 涉及数额、情节、人数 | **数字表**,单独成节 |
| 共犯、罪数、未完成形态 | **判断流程图**(代码块),按判断顺序排列 |
| 量刑情节 | 从重 / 从轻 / 减轻 / 免除,四栏表格(法考常在此设坑) |

## 学理与争议处理

- ⚠️ **体系一致性是硬要求**。主线老师用哪套体系,全科笔记就只用那套。不得因为"另一套更常见"而改写
- 老师明确说"这里有争议""通说认为"的,保留标注并注明老师主张
- 老师未提争议、直接给结论的,照写,**不得自行引入学派之争**
- 分则中老师给出的"实务倾向""指导案例观点",保留并标注来源
