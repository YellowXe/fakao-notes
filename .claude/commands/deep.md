# 深入版:$ARGUMENTS

参数按空格拆开理解,顺序不敏感:

- **素材目录** —— 如 `三国法` / `民法李建伟` / `民诉法`
- **专题号** —— 两位数字,如 `02`
- **子学科** —— 只有三国法需要:`国际公法` / `国际私法` / `国际经济法`。
  三国法未给子学科时**停下来问**,不要自己挑一个

## 先读这些文件(读完先声明你读到了哪几个)

1. `00_流程/目录映射.md` —— 查出**分科规范文件**、**输出目录**、**老师名**
2. 上一步查到的 `00_规范/<部门法>.md`
3. `CLAUDE.md` —— 特别是开头的「五条铁律」
4. `00_样本/反例/反例_典型幻觉形态.md` —— 七种形态,产出前后各自查一遍

⚠️ 分科规范文件读不到就**中止并报告**,不要用通用规则继续。

## 任务

### 第一步:先停下确认

输出「专题号 → 文件列表(按集号升序)」+ 各文件字数 + 目标输出路径,然后**停下等我说继续**。

同时检查:任一文件字数 < 2000 → 中止并报告,不要生成。

⚠️ 三国法只取该**子学科**的文件。另两个子学科同号专题的文件**不得混入**。

### 第二步:我说继续之后

按 CLAUDE.md 与分科规范产出深入版,写入映射表指定的目录:

- 单老师科目 → `<部门法>/专题NN <专题名>.md`
- 三国法 → `三国法/<子学科>/专题NN <专题名>.md`
- 双老师且主线未定 → `<部门法>/补充/专题NN <专题名>_<老师>.md`

frontmatter 的 `老师` 字段填映射表里查到的老师名。

### 第三步:自检

按 CLAUDE.md「处理完的自检」输出**四张表的实际结果**:
触发词覆盖表(实际计数)/ 高风险项溯源表(附 8–20 字字幕原文片段)/ 篇幅 / 被舍弃的考点。

⚠️ **只处理这一个专题,不要自动继续下一个。**
