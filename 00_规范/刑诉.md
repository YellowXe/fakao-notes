# 刑诉 分科规范

> 与 `CLAUDE.md` 配合使用。冲突时以本文件为准。

## 考试定位

- 程序法,客观题与主观题均考
- **期限密度全八科最高**,且几乎全部是法条硬性规定
- 另一大得分点是**办案机关权限**:同一件事,公安 / 检察院 / 法院谁有权做、谁批准、谁决定,是最高频的命题手法
- 学理争议少

## 篇幅

**深入版上限:输入字数的 25%。** 上限不得超过 30%。

## 专属输出要求

| 情形 | 必须产出 |
|---|---|
| 出现任何期限 | 汇入本专题**期限表**:事项 / 期限 / 起算点 / 延长条件 / 延长后总长 |
| 涉及多个办案机关 | **机关权限对照表**:公安 / 检察院 / 法院,横向对比谁决定、谁批准、谁执行 |
| 强制措施 | **对比表**:适用条件 / 期限 / 决定机关 / 批准机关 / 折抵 |
| 程序阶段 | **流程图**(代码块),标注各阶段期限 |
| 有例外、特别程序 | 原则 → 例外表(未成年人、认罪认罚、缺席审判等) |

## 冲刺版额外要求

冲刺版必须包含,且置于最前:

1. **全科期限总表**——这是刑诉冲刺版的核心,优先级高于选项速判表
2. **办案机关权限总表**
3. **强制措施横向对比总表**

## 数字纪律(本科加严)

刑诉的数字错一个就是一道题。除通用规则外:

- 每个期限必须写清**起算点**。只写"三日"不写从何时起算,视为未完成
- 涉及"可延长"的,必须写明延长条件与**延长后的总时长**
- 字幕中数字含混的,一律 `【?】`,**并在冲刺版待核清单中置顶**
