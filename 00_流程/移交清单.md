# 移交清单:强模型做范本 → 便宜模型跑量

> 分工前提:**深入版是幻觉高发区**(两万字非结构化输入),预习/冲刺版只是对已结构化的
> md 做压缩重排,风险低得多。所以钱要花在深入版的**模板定型**上,不是花在数量上。

---

## ⚠️ 不要一次性跑八科的前两个专题

两个原因,都会让钱白花:

**1. 模板还没定型。** 第一个范本跑出来极可能要调规范——篇幅上限偏紧、星级判定偏松、
某个专属输出要求没触发。一次跑十六个,调完规范这十六个全部作废重跑。

**2. 专题01 通常是导论,是全科最不能代表该科的一讲。** 内容浅、没有真题、
没有易混辨析、往往也不跨集。拿它当范本,便宜模型学不到"高密度专题怎么压缩"
"跨集怎么合并"——而这两件事恰恰是它最容易做错的。

---

## 分三个阶段,每阶段都有明确的止损点

### 阶段一:先只跑一个专题,把模板钉死

用强模型跑 **三国法 · 国际公法 · 专题02**。

选它的理由:跨三集(验合并逻辑)、`99_归档_旧版笔记/` 里有半个专题的旧产出可做对比基线、
三国法规范已有实测压缩比 35%。

```bash
DRYRUN=1 ./run.sh 三国法          # 先确认分组,不花钱
```

Claude Code 里:

```
/deep 三国法 国际公法 02
```

跑完立刻做三件事:

```bash
./verify.sh 三国法 02             # 零成本,先跑这个
```

| 检查 | 不合格怎么办 |
|---|---|
| `verify.sh` 全部命中 | 有「找不到」→ 先分清是没照抄原文还是编造 |
| 跨集覆盖完整 | 缺 003/004 的内容 → 分组或读入有问题,不要往下走 |
| 自检报告里「被舍弃的考点」为空 | 非空 → 上限过紧,上调 3 个点重跑 |

**这一步不通过,不要进阶段二。** 调完规范重跑,只亏一次调用。

### 阶段二:模板定型后,再用强模型铺其余七科范本

这时规范已稳,可以连着跑。每科**一个**范本,不是两个——第二个专题的边际收益很低,
钱留给阶段三的抽查。

选专题的原则(**都不要选专题01**):

| 优先级 | 条件 | 为什么 |
|---|---|---|
| 1 | **跨集**的专题 | 合并逻辑是最容易静默出错的地方 |
| 2 | 考点最密、该科最难的那一讲 | 范本要示范"压不下时怎么取舍" |
| 3 | 能触发该科**专属输出要求**的 | 见各科规范的「专属输出要求」表 |
| 4 | 字幕里**有真题解析**的 | 示范真题保留在原位、只留选项辨析 |

按第 3 条,各科建议:

| 科目 | 建议范本专题 | 触发的专属要求 |
|---|---|---|
| 国际私法 | 冲突规范/准据法那一讲 | **系属公式表** |
| 国际经济法 | 贸易术语(FOB、CIF)那一讲 | **风险转移点对比表** |
| 民法 | 物权变动 | 高密度学科验收,22% 上限是否够 |
| 刑法 | 犯罪构成 / 共同犯罪 | **两阶层还是四要件**——这是该科的体系分歧点 |
| 刑诉 | 强制措施 | 期限数字最密集,最能验数字零容忍 |
| 民诉 | 管辖 | 对比表密集 |
| 行政法 | 行政诉讼受案范围 / 起诉期限 | 期限 + 例外条款 |
| 理论法 | 法理学中较难的一讲 | 学理处理方式 |
| 商经知 | 公司法(股东权利或公司治理) | 主观题相关 |

⚠️ 民法和刑诉此时**主线老师还没定**。先跑 `/pick` 对比两位老师,定了主线再做范本——
否则范本可能出自你最终不用的那位老师。

范本验收通过后存进 `00_样本/正例/`:

```bash
mkdir -p 00_样本/正例
cp "三国法/国际公法/专题02 国际法主体和国际法律责任.md" \
   "00_样本/正例/三国法_国际公法_专题02.md"
```

并在该科规范文件里记一行 `范本: 00_样本/正例/xxx.md`。

### 阶段三:切便宜模型,但**第一个专题必须对比验收**

每科切换时,先只跑**一个**专题,拿它跟范本比。

```bash
DRYRUN=1 CLI="你的 reasonix 调用命令" ./run.sh 三国法 03
CONC=1  CLI="你的 reasonix 调用命令" ./run.sh 三国法 03
./verify.sh 三国法 03
```

对比检查表:

| 看什么 | 便宜模型常见的偏差 |
|---|---|
| `verify.sh` 结果 | 出现「找不到」→ 编造。**在数字/法条/真题上出现就别放开批量** |
| 星级分布 | 星级明显变多 → 它在用自己的判断标重要性,而不是老师的表态 |
| 有没有多出小节 | 凭空出现「主观题」「典型真题」→ 反例样本没起作用 |
| 表格有没有被填满 | 原文未讲的格子被补上 → 反例第 5 种形态 |
| 压缩比 | 显著低于范本 → 可能过度压缩,抽一节对字幕 |

通过了再放开:

```bash
CONC=1 CLI="..." ./run.sh 三国法              # 首批 3–5 个
./verify.sh 三国法                            # 全部校验
# → 回填错字表 → 再放开剩余
```

## 钱该怎么分配

| 环节 | 用哪个 | 理由 |
|---|---|---|
| 阶段一的模板定型 | **最强模型** | 一次做对,后面几百个专题都受益 |
| 各科范本(每科 1 个) | **最强模型** | 范本错了会被复制到几十个专题 |
| 其余深入版(绝大多数) | 便宜模型 | 量在这里 |
| 预习版 / 冲刺版汇总 | 便宜模型 | 输入已是结构化 md,是压缩重排不是理解 |
| 溯源校验 | **不用模型** | `./verify.sh`,纯 grep |
| 回填错字表 | 便宜模型 | 机械合并去重 |

强模型的调用次数 ≈ 1(定型)+ 10(各科范本,含三国法三个子学科)= **十来次**。
剩下几百个专题全归便宜模型。

---

## 便宜模型的三条硬要求

1. **温度 0–0.3。** 这一条的收益可能超过所有规范条文
2. **必须带上 `00_样本/反例/`。** 弱模型对"别做什么"的抽象指令响应差,
   对"这样是错的,看这里"响应强
3. **必须带上对应科目的 `00_样本/正例/` 范本。** 规范是抽象约束,范本是模仿目标,
   后者的认知成本低一个量级

⚠️ 带范本时要同时带 `CLAUDE.md` 的「参考样本的使用」一节——否则它会连范本里的
**法律内容**一起抄进来。

---

## 每科的收尾

```bash
./verify.sh <素材目录>        # 全科溯源校验
/backfill <素材目录>          # 回填错字表、待核条目、实测压缩比
/rollup <素材目录>            # 全部深入版完成后才做
```

⚠️ 跑批期间不要改 `CLAUDE.md` 和分科规范——前缀一变 prefix cache 全失效。要改等这批跑完。
