# 批量深入版:$ARGUMENTS

参数按空格拆开理解:**素材目录** / **专题范围**(如 `03-12` 或 `03,05,07`)/
**子学科**(仅三国法需要)。三国法未给子学科时**停下来问**。

## 先读这些文件(读完先声明你读到了哪几个)

1. `00_流程/目录映射.md` —— 查出分科规范文件、输出目录、老师名
2. 上一步查到的 `00_规范/<部门法>.md`
3. `CLAUDE.md` —— 特别是开头的「五条铁律」
4. `00_样本/反例/反例_典型幻觉形态.md`

⚠️ 分科规范文件读不到就**中止并报告**。

## 任务

### 开跑前

一次性输出全部分组结果(专题号 → 文件列表 → 字数 → 目标路径),**停下等我确认**。
字数 < 2000 的文件所属专题**整个跳过**,并在最后汇总报告。

⚠️ 三国法只处理指定子学科,不要跨子学科合并同号专题。

### 逐个处理

- 一次一个专题,**每个完成后输出自检表**,再进入下一个
- 目标文件已存在则**跳过**(幂等),并说明跳过原因
- 任一专题自检出现「因篇幅上限舍弃考点」→ **停下报告**,不要继续后面的

### 全部完成后

1. 汇总表:专题号 / 输入字数 / 输出字数 / 压缩比 / 是否触及上限 / 是否跳过
2. **停下。不要生成 `_预习.md` 和 `_冲刺.md`**(那是 `/rollup` 的事)
3. 提醒我该回填错字表了

⚠️ 首次批量建议只跑 3–5 个专题就停,回填错字表后再放开剩余的。

> 专题数多的科目(民法四十多个)建议改用 `./run.sh`,它自带分组、字数校验、
> 幂等跳过和并发控制。本命令适合十个左右的科目。
