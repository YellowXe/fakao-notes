# 提示词模板

> 每跑一个专题,复制下面的模板,**只改标着【】的地方**。
> 专属输出要求、篇幅上限、错字表这些都写在分科规范里了,**不要在提示词里重复**——
> 让模型自己去读,漏读了它会自己停下来问。

## 会话怎么开

**每个专题新开一个会话。** 不要在同一会话里连着跑多个专题。

| 原因 | 说明 |
|---|---|
| 上下文膨胀 | 一个专题输入三四万字、输出一万多字,连着跑两个就接近上限 |
| 串味 | 上一个专题的内容会渗进下一份笔记,跨子学科时尤其明显 |
| 成本没增加 | 规范文件内容不变,新会话的 prefix cache 照样命中 |

## 模板 A · 常规专题(某科已有范本)

```
你要把法考网课字幕整理成结构化学习笔记。先读取下列文件:

【规范类】
1. CLAUDE.md —— 通用规范。开头的「五条铁律」优先级最高,违反即作废重跑
2. 00_流程/目录映射.md —— 素材目录、分科规范、输出目录的对应关系
3. 上一步查到的分科规范 00_规范/【部门法】.md —— 与 CLAUDE.md 冲突时以它为准。
   特别注意:篇幅上限、「专属输出要求」表、专属 ASR 错字表、本科触发词变体
4. 00_样本/反例/反例_典型幻觉形态.md —— 七种典型幻觉形态,产出前后各自查一遍
5. 00_样本/正例/【本科范本文件名】.md —— 格式范本
   ⚠️ 只学格式(表格用法、星级位置、frontmatter、引用块、校对说明写法),
   不得取用其中任何法律内容,不得照搬其小节构成
6. 00_流程/自检报告模板.md —— 自检报告的固定格式

【素材】自己去 00_素材/【素材目录】/ 找出属于【专题号】的文件,
按集号升序全部读入,合并产出一个笔记。

分组规则:只抽两个数字 —— 文件名开头的连续数字 = 集号;「专题」之后的连续数字 =
专题号。不要解析整个文件名,分隔符风格不统一。

任务:产出深入版笔记,写入分科规范/目录映射指定的目录。

━━━ 先做这四件事,做完停下等我确认,不要直接开始写 ━━━

1. 逐个声明你实际读到了哪几个规范文件。读不到分科规范就中止并报告,
   不要用通用规则代跑
2. 输出分组结果:属于本专题的是哪几个文件,按集号升序列出
3. 报出各文件字数和总字数。⚠️ 字数指**字符数**(一个汉字算 1),不是字节数;
   报出后先自查量级,单集通常 8000–25000 字,超过 7 万几乎一定是数了字节
4. 从分科规范里读出本专题适用的篇幅上限百分比,算出上限字数,把这个数告诉我

━━━ 我确认后再开始写。写完做这些 ━━━

1. 严格执行分科规范里「专属输出要求」表的每一项 —— 那是本科笔记的主干
2. 自检报告写入 <输出目录>/_自检/专题NN.md,格式照模板,四张表全填
3. 溯源表的「字幕原文片段」必须原样照抄字幕,包括 ASR 错字 —— 字幕写错字就照抄错字,
   不要抄成笔记里改正后的规范表述,否则逐字检索必然失败
4. 片段 8–20 字,用反引号包裹,不要跨行截取
5. ⚠️ 溯源小节内除片段外不要出现任何反引号。标签、文件名一律不加,
   否则会被校验脚本当成待检片段而报假失败
6. 触发词计数用分科规范里记录的本科变体,不要照搬 CLAUDE.md 的通用词表

━━━ 最容易违反的三条,写之前再看一遍 ━━━

- 字幕里没有的,笔记里就没有。法条编号、例题、口诀、答题模板一律不得补充,
  即使你确知是对的
- 数字只能抄不能想。期限、比例、条文号照字幕写;含混或前后矛盾就标【?】并附原文片段
- 表述宁笨不改。不要把老师的口语表述「翻译」成教科书术语,那会引入字幕里没有的概念
```

## 模板 B · 某科的第一个专题(还没有范本)

用模板 A,但把第 5 项范本改成**近似科目的范本**并加一句说明,同时在末尾追加这一段:

```
━━━ 本科首次处理,额外报告这五项 ━━━

这是本科第一个专题,以下信息将回填进分科规范,供本科后续所有专题复用。
⚠️ 只报告和建议,不要自行写入规范文件。

1. **老师姓名** —— 从字幕里识别(老师常自称「X 老师」),报出依据

2. **本科触发词变体** —— 老师提示考点的实际说法是什么?
   逐个统计「必考 / 年年考 / 这是考点 / 考试会考 / 勾一下」在字幕中的出现次数。
   若全部为 0,说明这位老师用的是别的说法,找出来并统计其 ASR 变体
   （例:三国法杨老师只说「勾X」,ASR 识别为 构出 / 扣出 / 够出）
   ⚠️ 这一项不做,本科后续所有专题的触发词计数都会是 0,自检等于失效

3. **篇幅上限是否合适** —— 报出实测压缩比;是否有考点因上限被迫舍弃;
   建议的上限值及理由

4. **初始 ASR 错字表** —— 本专题实际改动的字词,按频次降序;
   「两边都是真词」性质的单独列出为高危同音组,不要放进可直接替换表

5. **主观题** —— 本科分科规范标注主观题适用时:老师有没有给答题步骤、
   答题结构、采分表述?给了就设 ## 主观题 小节,没给就整节省略,不得自编
```

## 各科变量速查

| 素材目录 | 分科规范 | 输出目录 | 上限参考 | 需指定子学科 | 双老师 |
|---|---|---|---|---|---|
| `三国法` | `三国法.md` | `三国法/<子学科>/` | 35% / **38%**(跨三集+) | **是** | 否 |
| `刑法` | `刑法.md` | `刑法/` | 22% | 否 | 否 |
| `民法李建伟` `民法孟献贵` | `民法.md` | `民法/` 或 `民法/补充/` | 22% | 否 | **是** |
| `民诉法` | `民诉.md` | `民诉/` | 25% | 否 | 否 |
| `刑诉向高甲` `刑诉左宁` | `刑诉.md` | `刑诉/` 或 `刑诉/补充/` | 25% | 否 | **是** |
| `行政法` | `行政法与行政诉讼法.md` | `行政法与行政诉讼法/` | 25% | 否 | 否 |
| `理论法` | `理论法.md` | `理论法/` | 20% | 否 | 否 |
| `商经知` | `商经知.md` | `商经知/` | 22% | 否 | 否 |

⚠️ 上限参考值只用于你心算核对量级,**实际以分科规范里的数为准**(会随校准变动)。

### 三国法要在模板 A 的素材段追加

```
⚠️ 00_素材/三国法/ 混装三个子学科(国际公法、国际私法、国际经济法),
靠文件名区分,而三者各自都有同号专题。只按专题号分组会把不相干内容合并成一份笔记,
而产出看起来仍然完整 —— 这是最难察觉的一类错误。

判子学科:含「国际私法」→ 国际私法;含「国际经济法」→ 国际经济法;
含「国际法」且不含前两者 → 国际公法。⚠️ 顺序不可颠倒。

本次只取【子学科】的【专题号】。
```

## 三个范本各科都要有

范本是给便宜模型对齐格式用的,而各科专属输出要求差异很大,**不能跨科套用**:

| 科目 | 建议范本专题 | 因为它能触发 |
|---|---|---|
| 国际公法 | 专题02(已完成) | 口诀、豁免对比表 |
| 国际私法 | 专题03 冲突规范适用 | **系属公式表** |
| 国际经济法 | 专题02 国际货物买卖法 | **贸易术语对比表** |
| 民法 | 物权变动 | 要件对比表、期限表 |
| 刑法 | 犯罪构成 / 共同犯罪 | **两阶层还是四要件** |
| 刑诉 | 强制措施 | 期限表最密集 |
| 民诉 | 管辖 | 管辖表 |
| 行政法 | 受案范围 / 起诉期限 | 可诉不可诉对照表 |
| 理论法 | 法制史某讲 | 朝代时间轴 |
| 商经知 | 公司法(表决比例那块) | **比例表** |

选题原则:优先**跨多集**的、**考点最密**的、**能触发本科专属输出要求**的。
⚠️ 都不要选专题01 —— 导论最浅,示范不出跨集合并和高密度压缩。
