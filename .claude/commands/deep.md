# 深入版:$1 专题 $2

## 先读这些文件(读完先声明你读到了哪几个)

1. `CLAUDE.md` —— 特别是开头的「五条铁律」
2. 分科规范文件 —— 按下表确定:
   - `国际法` / `国际私法` / `国际经济法` → `00_规范/三国法.md`
   - 含下划线的取前段:`民法_张` → `00_规范/民法.md`
   - 其余同名:`刑法` → `00_规范/刑法.md`
3. `00_样本/反例/反例_典型幻觉形态.md` —— 七种形态,产出前后各自查一遍
4. 若 `00_样本/` 下有正例笔记,读一份对齐格式(⚠️ 只学格式,不取内容)

⚠️ 分科规范文件读不到就**中止并报告**,不要用通用规则继续。

## 任务

处理 `00_素材/$1/` 中**专题号为 $2** 的全部文件,合并产出**一个**深入版。

### 第一步:先停下确认

输出「专题号 → 文件列表(按集号升序)」+ 各文件字数,然后**停下等我说继续**。

同时检查:任一文件字数 < 2000 → 中止并报告,不要生成。

### 第二步:我说继续之后

按 CLAUDE.md 与分科规范产出深入版,写入 `<部门法>/专题$2 <专题名>.md`。

### 第三步:自检

按 CLAUDE.md「处理完的自检」输出**四张表的实际结果**:
触发词覆盖表(实际计数)/ 高风险项溯源表(附 8–20 字字幕原文片段)/ 篇幅 / 被舍弃的考点。

⚠️ **只处理这一个专题,不要自动继续下一个。**
