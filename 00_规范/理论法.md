# 理论法 分科规范

> 与 `CLAUDE.md` 配合使用。冲突时以本文件为准。

## 考试定位

- 覆盖法理学、宪法、法制史、司法制度与法律职业道德等板块,各板块性质差异很大
- **以记忆型考点为主**,案例式考察比重低于其他各科
- 主观题有论述题,需要成段表述能力

## 篇幅

**深入版上限:输入字数的 20%**——八科中最狠。

原因:本科字幕的叙述性铺垫最多(尤其法制史带大量朝代故事、宪法带大量制度沿革),而真正的考点是高度浓缩的结论与数字。压缩空间最大。上限不得超过 25%。

## ⚠️ 通用规则的例外

`CLAUDE.md` 中"保留案例本身,压缩叙述"这条**在本科基本不适用**。本科的"案例"多为历史叙事或制度背景,不是考点载体。

替代规则:

- 历史叙事、制度沿革一律压成**结论 + 时间/主体/关键特征**,不保留故事
- 唯一例外:法律职业道德的**情形题**(某律师某行为是否违规),这类必须保留情形本身,因为它就是考点形态

## 专属输出要求

| 板块 | 必须产出 |
|---|---|
| 法制史 | **朝代时间轴 + 制度对照表**:朝代 / 代表性法典 / 关键制度 / 首创之处("首创""最早"是命题密集区) |
| 宪法 | **数字表**:任期、人数、比例、届次;**职权对照表**:各国家机关横向对比谁有何权 |
| 法理学 | **概念辨析表**;学派/观点对照表 |
| 职业道德 | **情形—定性对照表**:行为 / 是否违规 / 依据 / 后果 |
| 一切"首创 / 最早 / 唯一 / 首次" | 单独汇总成节——这是本科最高频考法 |

## 冲刺版额外要求

1. **口诀总表**——本科记忆量大,口诀是主要抓手,必须集中
2. **数字总表**(宪法为主)
3. **"首创 / 最早"总表**
4. 主观题论述常考主题清单(老师提到的,只列不展开)

⚠️ 本科特有的高危同音组:

- 朝代与法典名称 ASR 错误率最高,**凡法典名、朝代名、人名一律逐处核对**,拿不准即 `【?】`

- **人大 / 认打**

- **备案 / 报案**
